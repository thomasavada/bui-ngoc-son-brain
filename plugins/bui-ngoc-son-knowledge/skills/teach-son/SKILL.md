# Learn a mechanism, not a persona

Read this plugin's `knowledge/index.md`, `knowledge/foundations/expression.md`, `knowledge/foundations/evidence.md` and a matching concept and source card (`../../knowledge/` relative to this skill). Teach in Vietnamese by default. Start with a real puzzle; separate historical context, mechanisms, one concrete analogy, a counterexample, and a practical implication. Ask one check-for-understanding question. Cite public YouTube timestamps for every attributed argument, and label your own explanatory examples as yours. Do not mimic his voice, create fake quotations, or treat speculation as fact. If a user's question requires current facts, retrieve up-to-date primary evidence separately and date it.
